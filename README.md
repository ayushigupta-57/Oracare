# Oracare — daily loop (Flutter)

Flow 2 "daily loop": Lock-screen reminder → Home → Routine (Morning/Evening) → guided steps → check-in (+20 HP) → Oral Report.
Everything outside the loop is visible but not tappable.

Build: push to `main`; GitHub Actions builds the APK (Actions → latest run → Artifacts → `oracare-daily-apk`).

Images: drop `hero.png` (toothbrush photo) and `mouth.png` (tooth-map illustration) into `assets/images/`.
